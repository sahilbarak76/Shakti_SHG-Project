# Shakti SHG Store — CSE326 CA2

A responsive frontend prototype for a hypothetical online storefront showcasing products inspired by rural women-led Self-Help Groups (SHGs).

## Run locally
1. Extract this folder.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No build tools or installation are required.

## Features
- Responsive layout and mobile navigation
- Product cards with illustrative sample products
- Search and category filtering
- Add-to-cart, quantity updates, remove item, subtotal
- Demo contact form with local confirmation
- Demo checkout notice (no real orders/payments)

## Important limitations
- Product names, prices, maker names and illustrations are sample content for an academic prototype.
- No database, authentication, real inventory, backend, email delivery or payment gateway is connected.
- Contact form and checkout do not send or save data to a server.
- For a real deployment, get permission from SHGs, verify product information, add a secure backend, privacy policy and accessible order workflow.

## Files
- `index.html` — page structure
- `style.css` — design and responsive styles
- `script.js` — product filtering and cart interactions
- `Project_Report.docx` — editable project report
- `Project_Presentation.pptx` — editable presentation
